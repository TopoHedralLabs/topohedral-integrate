Struct GaussRuleSet 

Source 
pub struct GaussRuleSet { /* private fields */ }
Expand description

A collection of Gauss quadrature rules through a maximum requested exactness degree.

See the Gaussian-rules guide.

Source

pub fn through_degree( family: GaussFamily, degree: PolynomialDegree, ) -> Result<Self, RuleError>

Builds every rule for family through the requested polynomial exactness degree.

§Errors

Returns RuleError::DegreeOutOfRange when degree exceeds 100, or RuleError::GenerationFailed if the eigendecomposition backend fails.

Source

pub fn rule_for_degree( &self, degree: PolynomialDegree, ) -> Result<&GaussRule, RuleError>

Returns the smallest stored rule whose exactness is at least degree.

§Errors

Returns RuleError::DegreeOutOfRange when degree exceeds the maximum requested while constructing this set.

Source

pub fn rule_by_point_count( &self, point_count: PointCount, ) -> Result<&GaussRule, RuleError>

Returns the stored rule containing exactly point_count points.

§Errors

Returns RuleError::PointCountOutOfRange when point_count is not represented by this set.
